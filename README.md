## 📌 About The Project

**GradeAI** is a TypeScript-powered academic web application designed to modernize assignment submission and evaluation workflows.

It provides:

- Structured digital assignment submission  
- AI-powered writing consistency insights  
- Role-based dashboards (Student / Teacher / Admin)  
- Real-time academic interaction experience  

The AI component acts strictly as a **decision-support system** — final grading authority remains with the teacher.

---

## ✨ Key Features

### 👨‍🎓 Student Dashboard
- Secure authentication
- View assigned assessments (Assessment 1, Assessment 2, etc.)
- Submit assignments
- Track submission status
- Receive AI writing feedback
- View grades

### 👩‍🏫 Teacher Dashboard
- Create and manage assessments
- Define due dates and total marks
- Review student submissions
- Access detailed AI metrics
- Assign grades and remarks

### 🛡 Admin Dashboard
- Manage users
- Assign roles
- Monitor system workflow

---

## 🤖 Writing Analysis Engine

GradeAI evaluates:

- Word Count  
- Sentence Count  
- Average Sentence Length  
- Repetition Index  
- Readability Score  
- Consistency Score  

AI assists evaluation — it does not replace teacher judgment.

## 🛠 Getting Started

### 📋 Prerequisites

- Node.js v18 or higher  
- npm or yarn  

---

### 📦 Installation

```
git clone https://github.com/yourusername/gradeai.git
cd gradeai
npm install
```

---

### ▶️ Run Development Server

```
npm run dev
```

Application runs at:

```
http://localhost:5173
```

---

## 🚀 Deployment

GradeAI is deployed using **Vercel**.

### Deploy Steps

1. Push project to GitHub  
2. Import repository in Vercel  
3. Click Deploy  

No additional server configuration required.
